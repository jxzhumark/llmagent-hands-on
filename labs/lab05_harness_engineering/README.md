# Lab 05: Harness Engineering for Agent Runtime

Build an agent harness from the perspective of RL policy-environment interaction. The harness sets up and maintains the runtime environment in which an agent receives observations, takes actions, and produces long-horizon trajectories reliably.

## Topics

- Environment setup and reset
- State and observation
- Action space and tool execution
- Environment transition
- Episode and trajectory management
- Termination and truncation
- State checkpointing and rollout resumption
